dreader on the map: every file it keeps, every place it writes, and what its public release still needs

dreader is an EPUB and PDF reader built with Tauri 2 whose record belongs to the reader: JSON files, one directory per book, with a SQLite index that can be thrown away and rebuilt. This page is the record and the derived files with their formats, the data root and how it is chosen, the footprint on a Mac, which vendor fact each release decision rests on, and the state of the release requirements at one commit.

§1

The data root and how it is chosen

factkindsource
The root is chosen at run time, in order: the DREADER_HOME environment variable (tests and scripts); the DataRoot key in the preferences domain com.clubstraylight.dreader, read through CFPreferences; then ~/Library/Application Support/dreader/. "No path is compiled into the binaries." An empty value counts as unset; a relative one is an error naming its source. dreader paths prints the root in effect and what chose it.familyD · on-disk-layout.md; ADR-0010 as built; DR-0042
Why a preference and not only a variable: "An app launched from Finder does not see shell variables." Why not ~/Documents/dreader: with "Desktop and Documents Folders" on, iCloud syncs it and may evict files, so the record would depend on Apple's service. Why Application Support: "the place macOS apps keep data the user did not create as documents. Time Machine includes it".familyD · ADR-0010 §1
When the root cannot be created or written, the app shows the path, the source, and the error, with "Choose Folder…" (a folder that passes the root check is written to DataRoot and used at once) and "Quit". It never runs silently without a record.familyD · on-disk-layout.md; PRD-0002 R-I3
The author's record lives in a folder of their own outside the repository, named by DataRoot, since 2026-10-12; data/ left the source tree. (Its path is the author's and is not on this page.)familyD · ADR-0010 as built, Q1
~/Library/Application Support/dreader and ~/Library/Preferences/com.clubstraylight.dreader.plist both exist on the author's Mac.observedO1 · 2026-10-13
The folder name is the product name, dreader, where Apple's convention is the bundle identifier or the company (places §3); the frameworks' folders for the same app are under com.clubstraylight.dreader.familyD · on-disk-layout.md; A2

The record: files and formats

The record is "the only thing dreader holds that cannot be made again": about 1.5 MB for a library of 400 books on 2026-10-10, growing with reading rather than with the library. Every record file carries a schema integer.

The book id

The first 16 hexadecimal characters of the SHA-256 of the first file version dreader saw; shasum -a 256 book.epub | cut -c1-16 names the directory. An unpacked EPUB directory is hashed as a tree (path, NUL, bytes, NUL, in sorted path order). A collision with different content extends the new id to 32 characters. D · on-disk-layout.md § Book id

Writing rules, every record file

  1. Write to <name>.json.tmp-<pid>-<n>-<random> in the same directory, fsync, rename over the target, fsync the directory. A read-modify-write holds an exclusive flock on the file's directory from read to rename; the app, the CLI and their threads all take it. Temporary files older than an hour are removed when the root is prepared.
  2. Pretty-printed, two-space indent, keys in schema order, "so diffs are readable and git on the data root is a usable history".
  3. The mtime at read is recorded; a file changed underneath is reloaded and merged by item id, newest modified wins.
  4. A file that does not parse or validate is reported with path, line and message, and never overwritten.

Versioning: the app reads any schema it knows and writes the current one; a migration keeps the original as <name>.json.v<n> beside it until the reader deletes it. D · on-disk-layout.md § Writing rules, Versioning; DR-0062

§8

Gaps

  • The annotation schema's fields are not reproduced here; the file named in §2 is the source.
  • The record's exact size and the library's count on the author's Mac were not measured for this page; the 1.5 MB figure is ADR-0010's on 2026-10-10.
  • Whether DR-0045 (the log) is built is contradicted between PRD-0002 §3.1 and the inventory; the folder exists. The ticket is the arbiter and was not read.
  • The /usr/local/bin link, the privacy grants, and the Launch Services dump were not checked on the author's Mac for this page.
  • The guide EPUB, the launchd agent, the Keychain items, and the update path are planned and have no observed facts.
